Usage de l'IA
Développée avec l'aide d'une IA (Claude, d'Anthropic) pour écrire et remanier le code, les tests et les scripts de compilation, et pour proposer les traductions. L'auteur a conçu l'appli, puis relu, testé et débogué le code sur de vraies installations de Skyrim. Icône, écran de démarrage et illustrations réalisés avec l'aide de l'IA ; les captures sont de vraies captures de l'appli. Code source public sur GitHub.
