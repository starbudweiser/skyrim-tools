# Skyrim Tools

## About

**Skyrim Tools** is a family of native macOS apps for installing, creating and fixing Skyrim mods. Every app is free, signed and notarized by Apple, and translated into French, English, Spanish and Italian.

This repository is the source of the showcase website and press kit: <https://starbudweiser.github.io/skyrim-tools/>. Downloads are served by each app's GitHub Releases page.
